# Quickstart: Physical AI & Humanoid Robotics Course Book

This guide explains how to build and read the Physical AI & Humanoid Robotics course book.

## Prerequisites

- Node.js (v18 or later)
- Yarn

## Installation

1.  Clone the repository:
    ```bash
    git clone https://github.com/farahmuzaffar/testing-api-fast.git
    ```
2.  Navigate to the `book` directory:
    ```bash
    cd physical-ai-book/book
    ```
3.  Install the dependencies:
    ```bash
    yarn install
    ```

## Building the Book

To build the Docusaurus website, run the following command from the `book` directory:

```bash
yarn build
```

The output will be in the `book/build` directory.

## Reading the Book

To start a local development server and read the book in your browser, run the following command from the `book` directory:

```bash
yarn start
```

This will open a browser window at `http://localhost:3000`.
