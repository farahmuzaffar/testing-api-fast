# Data Model: Physical AI & Humanoid Robotics Course Book

This document defines the structure of the content for the Physical AI & Humanoid Robotics course book.

## Book

The root entity of the book.

- **title**: The title of the book.
- **overview**: A high-level overview of the course.
- **motivation**: Why Physical AI is an important field of study.

## Module

A module represents a major topic in the course.

- **title**: The title of the module (e.g., "ROS 2").
- **summary**: A brief summary of the module.
- **key_concepts**: A list of key concepts covered in the module.
- **learning_outcomes**: A list of learning outcomes for the module.

## Weekly Plan

A week-by-week breakdown of the course.

- **week_number**: The week number (1-13).
- **topic**: The main topic for the week.
- **lab**: A description of the lab for the week.
- **readings**: A list of required readings.

## Assessment

An assessment is a graded component of the course.

- **title**: The title of the assessment (e.g., "ROS 2 Project").
- **description**: A description of the assessment.
- **weight**: The weight of the assessment in the final grade.

## Hardware Tier

A hardware tier represents a specific hardware configuration.

- **tier_name**: The name of the tier (e.g., "Entry-Level", "Recommended").
- **workstation_specs**: The specifications for the workstation.
- **jetson_kit**: The recommended Jetson kit.
- **robot_options**: A list of recommended robot platforms.
